## Atajos de Eclipse

Los vas a usar en todas las lecciones.

| Atajo | Qué hace |
| --- | --- |
| Ctrl + S | Guardar el archivo |
| Ctrl + F11 | Ejecutar el programa |
| Ctrl + Espacio | Autocompletar (probá escribir `sysout` y después Ctrl + Espacio) |
| Ctrl + 1 | Ver arreglos rápidos para el error donde está el cursor |
| Ctrl + Shift + F | Ordenar la sangría de todo el código |
| Ctrl + Shift + O | Agregar los `import` que faltan |
| Ctrl + Z | Deshacer |
